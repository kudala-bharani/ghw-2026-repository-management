# Mergington High School Security Policy

This is a fictional GitHub Skills practice project, prepared with AI assistance. Do not submit real student data or credentials.

## Reporting a Vulnerability
Please do not disclose vulnerabilities in public issues or discussions. Use this repository's Security tab and select Report a vulnerability to send a private report to the repository owner. Include a description, reproduction steps using synthetic data, potential impact, and any suggested fix.

In the course's fictional school scenario, reporters also notify the IT Club faculty advisor at techsupport@mergingtonhigh.example.edu without including vulnerability details. This is an example address, not a real support contact.

## Response Timeline
The exercise scenario illustrates acknowledgment within 2 school days, initial assessment within 5 school days, immediate attention to critical student-data issues, and collaboration in a private fork to prepare fixes. These are fictional learning examples, not a service-level commitment by this practice repository.

## Thank You
Responsible disclosure helps maintainers address issues safely. Thank you for helping keep the project secure.
